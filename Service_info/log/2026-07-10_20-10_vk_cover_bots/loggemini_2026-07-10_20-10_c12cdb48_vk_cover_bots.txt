ВЫПОЛНЕННЫЕ РАБОТЫ:

1. Разработаны модели базы данных в backend/app/models/vk_cover_bot.py:
   - VkCoverBot: для сохранения настроек активной обложки группы (фон, город, JSON виджеты).
   - VkCoverSubscriberActivity: для кэширования баллов активности подписчиков (топ недели по лайкам/комментариям).
2. Зарегистрированы новые модели в модуле инициализации backend/app/models/__init__.py.
3. Создан скрипт создания таблиц в PostgreSQL на VPS: backend/app/scripts/create_vk_cover_bot_tables.py.
4. Разработан сервис backend/app/services/vk_cover_service.py:
   - Автозагрузка и кэширование кириллического шрифта Roboto-Bold.ttf для Pillow.
   - Рендеринг виджетов с помощью Pillow (Часы, Погода с Open-Meteo API без ключей, Таймер, Произвольный текст, Топ-активный подписчик недели с круглой аватарой и именем).

   - Интеграция API ВК для загрузки обложки: photos.getOwnerCoverPhotoUploadServer -> POST -> photos.saveOwnerCoverPhoto.
5. Написан FastAPI контроллер backend/app/api/vk_cover_bots.py:
   - CRUD операции для настроек обложки группы.
   - Загрузка фоновых изображений в /media/img/vk_covers/.
   - Эндпоинт POST /preview для динамической генерации и возврата base64-превью картинки для конструктора во фронтенде.
   - Эндпоинт POST /{bot_id}/publish-now для ручного обновления обложки в ВК.
6. Зарегистрирован роутер в backend/app/api/__init__.py и подключен в backend/main.py.
7. Созданы Celery задачи в backend/app/tasks/vk_cover_task.py:
   - vk_cover_update_task: ежеминутное обновление обложек в ВК для активных ботов.
   - vk_cover_activity_sync_task: расчет активности подписчиков раз в 30 минут с кэшированием в БД.
8. Задачи зарегистрированы в Celery приложении backend/app/core/celery_app.py.
