# Лог изменений: Исправление выгрузки выписок Т-Банк API

**Дата:** 2026-06-02  
**Задача:** Исправление проблемы с невключением сегодняшнего дня в диапазон выписки Т-Банка (not inclusive till) и некорректным разбором структуры JSON-ответа, приводящих к 0 транзакций в выписке.

## Выполненные изменения

### 1. Бэкенд (`backend/app/api/tbank.py`)
- Добавлено автоматическое прибавление 1 дня к дате `till_date` при отправке запроса в Т-Банк (так как параметр `till` в Т-Банке невключителен: `not inclusive`). Это решает проблему 0 транзакций при запросе выписки за сегодня.
- Переписан разбор JSON-ответа API в `sync_tbank_statement` для поддержки ключей `"operation"`, `"operations"`, `"content"`, а также вложенных в `"payload"` данных.
- Реализован устойчивый парсинг полей транзакции (`chargeDate`/`date`/`drawDate`/`operationDate`, `paymentPurpose`/`purpose`/`description`, `amount`/`payment`) с автоматическими фолбэками.
- Локальная проверка синтаксиса компилятором `py_compile` пройдена успешно.

## План тестирования и синхронизации
1. Выгрузка измененных файлов на VPS через `sync_to_vps.py`.
2. Перезапуск контейнеров бэкенда и воркера.
3. Проверка запроса выписки за сегодня в админ-панели.
