Лог сессии: 2026-07-15_22-05_fix_manual_sync_check
Задача: Устранение ошибки "Синхронизация с iiko отключена в настройках" при ручном запуске синхронизации баллов активности.

Анализ проблемы:
В таблице `vk_activity_settings` у подключения флаг `sync_with_iiko` равен `false`.
Когда администратор открывает настройки и включает переключатель "Синхронизация с iikoCard" (во фронтенде `sync_with_iiko` временно становится `true`), появляется кнопка "Запустить синхронизацию".
При ее нажатии отправляется запрос на ручную синхронизацию.
На бэкенде в `run_manual_iiko_sync` происходит проверка:
```python
if not settings or not settings.sync_with_iiko:
    return {"status": "error", "message": "Синхронизация с iiko отключена в настройках"}
```
Так как настройки в БД еще не сохранены (администратор не нажал кнопку "Сохранить" внизу диалога), бэкенд возвращает ошибку.
Даже если настройки сохранены, ручной запуск синхронизации баллов не должен жестко требовать включенной фоновой/автоматической синхронизации (которая начисляет бонусы за каждое Callback-событие). Администратор может хотеть запускать синхронизацию только вручную.

Решение:
Убрать жесткую проверку флага `sync_with_iiko` при ручном запуске синхронизации в методе `run_manual_iiko_sync`.

Изменения:
В `backend/app/services/vk_activity_service.py`:
Заменить:
```python
if not settings or not settings.sync_with_iiko:
    return {"status": "error", "message": "Синхронизация с iiko отключена в настройках"}
```
на:
```python
if not settings:
    return {"status": "error", "message": "Настройки активности для этого подключения не найдены"}
```

План проверки:
1. Применить изменения в локальном `backend/app/services/vk_activity_service.py`.
2. Выгрузить изменения на VPS-сервер.
3. Провести сверку содержимого файла на VPS.
4. Перезапустить контейнеры backend и worker.
5. Проверить запуск ручной синхронизации.
