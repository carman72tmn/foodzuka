# Лог задачи: Скрытие кнопки выбора способа оплаты для курьера, если заказ уже полностью оплачен в iiko
**Дата и время**: 05.09.2026 00:25
**Сессия**: hide_courier_payment_button_if_paid
**Задача**: В меню «Курьеры» (/pers/courier), если заказ уже полностью оплачен в iiko, скрывать кнопку выбора способа оплаты («Оплата» / «Оплатить») для курьера, и при нажатии кнопки «Доставлен» сразу фиксировать завершение доставки без открытия диалогов выбора способа расчета.

## План реализации
1. Добавить в courier.vue надежную функцию isOrderFullyPaid(order).
2. В карточке заказа при статусах доставки (onway / delivering) скрывать кнопку «Оплата» (openChangePaymentDialog), если isOrderFullyPaid(order) истинно.
3. При статусе delivered скрывать кнопку «Оплатить» (openCloseDialog), если заказ уже оплачен.
4. В обработчике handleDeliveredClick при полной оплате заказа сразу переводить в Delivered без открытия окон выбора способа расчета.
5. Проверить сборку фронтенда, выгрузить на VPS, сверить SHA-256 хэши, пересобрать проект и протестировать.

## Реализованные изменения:
1. **Функция всеобъемлющей проверки оплаты**:
   - В `admin/resources/js/pages/employee/courier.vue` создана функция `isOrderFullyPaid(order)`.
   - Проверяются критерии:
     - Оплата через СБП в текущей сессии (`sbpSuccessOrders.has(order.id)`).
     - Флаг `order.is_paid` при отсутствии остатка (`left_to_pay <= 0`).
     - Фактическая оплата полной стоимости по `payments_details.items` из iiko Cloud.
     - `left_to_pay <= 0` при ненулевой сумме заказа и установленном признаке оплаты.

2. **Скрытие и блокировка кнопок выбора способа оплаты**:
   - Кнопка **«Оплата»** (выбор способа расчета на маршруте доставки `onway`/`delivering`): добавлен `v-if="!isOrderFullyPaid(order)"`. Для уже оплаченного заказа отображается только кнопка «Доставлен».
   - Кнопка **«Оплатить»** при статусе `delivered`: условие обновлено на `v-else-if="order.status.toLowerCase() === 'delivered' && !isOrderFullyPaid(order)"`. Если заказ оплачен, выводится кнопка «Подробнее».
   - Дополнительная круглая кнопка вызова деталей: условие скорректировано `(order.status.toLowerCase() === 'delivered' && !isOrderFullyPaid(order))`, исключая дублирование двух кнопок «Подробнее».
   - Плашка **СБП**: условие показа статуса «Оплачено» приведено к единому критерию `v-if="isOrderFullyPaid(order)"`.

3. **Логика завершения доставки**:
   - В `handleDeliveredClick`: если `isOrderFullyPaid(order)`, заказ мгновенно переводится в статус `Delivered` вызовом `updateStatus(order.id, 'Delivered', true)` без показа модальных окон выбора оплаты.
   - В `updateStatus`: автоматическое открытие диалога оплаты при переходе в `Delivered` заблокировано для оплаченных заказов (`!isOrderFullyPaid(order)`).
   - В `openChangePaymentDialog` и `openCloseDialog`: добавлен guard-контроль с информационным уведомлением `toast.info('Заказ уже полностью оплачен в iiko')`.
   - В `hasOrderPaymentMethod`: интегрирована проверка `if (isOrderFullyPaid(order)) return true`.

4. **Выгрузка и сверка**:
   - Локальный файл `admin/resources/js/pages/employee/courier.vue` выгружен на VPS через scp.
   - SHA-256 хэши локального и удаленного файлов сверены байт-в-байт: `c3b57af586ec2f99b9eaf9548933fdc6b979135236ccb51a3e98a6589843334b`.
   - Запущена пересборка фронтенда (`npm run build`).
