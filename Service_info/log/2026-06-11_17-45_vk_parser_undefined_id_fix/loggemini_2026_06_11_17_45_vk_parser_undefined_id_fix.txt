Task: Исправление ошибки отображения ID undefined в Истории сообщений VK парсера для несвязанных пользователей.

[Описание проблемы]
Во вкладке "Мониторинг сообщений" настроек ВК парсера (`/settings/vk-parser`) для сообщений некоторых пользователей отображалось имя "ID undefined" и генерировалась нерабочая ссылка вида `https://vk.com/idundefined`.
Причина: во фронтенд-компоненте `vk-parser.vue` при отображении строки сообщения ошибочно считывалось свойство `msg.vk_user_id`:
```vue
<a :href="`https://vk.com/id${msg.vk_user_id}`" ...>
  {{ msg.user?.first_name ? ... : `ID ${msg.vk_user_id}` }}
</a>
```
Однако в структуре возвращаемой бэкенд-модели `VkMessage` свойства `vk_user_id` нет, а реальный ID пользователя лежит в свойстве `peer_id` (идентификатор собеседника).

[План решения]
1. Сделать резервную копию `vk-parser.vue` в trash.
2. Обновить `admin/resources/js/pages/settings/vk-parser.vue`: заменить `msg.vk_user_id` на `msg.peer_id` на строках 1222-1223.
3. Синхронизировать файлы на VPS и запустить пересборку фронтенда.
4. Зафиксировать изменения в system_faq.md.

[Выполнение и Результаты]
1. Сделана резервная копия.
2. В файле `vk-parser.vue` локально заменен `msg.vk_user_id` на `msg.peer_id`.
3. Запущен скрипт `sync_to_vps.py`. Изменения выгружены, фронтенд успешно пересобран (`npm run build` в admin), контейнеры перезапущены.
4. system_faq.md обновлен и выгружен на сервер.
5. Лог выгружен на сервер.
