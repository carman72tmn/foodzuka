# Лог сессии: Исправление версии API расчетных счетов Т-Банка с v4 на v3

* **Дата сессии**: 02.06.2026
* **Время сессии**: 22:10
* **Задача**: Исправление ошибки `Not Found` (HTTP 404) при получении счетов из Т-Банк API.

## Состояние до изменений

В файле `backend/app/api/tbank.py` на строках 108 и 347 для вызова OpenAPI расчетных счетов Т-Банка использовался устаревший или некорректный URL с версией API `v4`:
- `https://business.tbank.ru/openapi/api/v4/bank-accounts`
В официальном OpenAPI Т-Банка (T-API) для получения списка счетов используется версия `v3`:
- `https://business.tbank.ru/openapi/api/v3/bank-accounts`
Из-за этого API Т-Банка возвращал ошибку `404 Not Found`, что мешало выгрузке реальных выписок.

## Планируемые изменения

1. Отредактировать [tbank.py](file:///c:/Users/v_kva/.gemini/antigravity/scratch/foodtech/backend/app/api/tbank.py): заменить `/api/v4/bank-accounts` на `/api/v3/bank-accounts` в методах `test_tbank_connection` (строка 108) и `get_tbank_accounts` (строка 347).
2. Проверить синтаксис локально через `py_compile`.
3. Задеплоить на VPS с помощью `sync_to_vps.py` и перезапустить бэкенд.
