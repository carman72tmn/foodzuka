# Лог сессии: Проверка и доработка real-time режима
Дата создания: 2026-06-21T16:15:00+05:00
Дата завершения: 2026-06-21T16:30:00+05:00
Задача: Проверить и исправить live-режим (WebSockets, уведомления, автообновление) для заказов, доставок, уведомлений и платежей.

## Найденные проблемы и пробелы:
1. **Смена статуса заказов**: При изменении статуса заказа в `iiko_sync_service.py` (например, отмена `cancelled` или обновление статуса) по WebSocket ничего не отправлялось. Соответственно, в админке список заказов не обновлялся в реальном времени и не всплывали Toast-уведомления об изменении статуса или отмене.
2. **Снятие курьера с доставки**: При отмене назначения курьера (`delivery_unassigned` при не-новом заказе) WebSocket-событие не отправлялось курьеру и в общую сеть.
3. **Панель курьера (`courier.vue`)**: Обработчик WebSocket в `courier.vue` не реагировал на событие снятия курьера (`delivery_unassigned`) и на изменение адреса (`change_address`), из-за чего страница не обновлялась реактивно.
4. **Т-Банк импорт выписки по API**: В методе `sync_tbank_statement` (`tbank.py`) при добавлении новых платежей не отправлялись WebSocket-сообщения `new_bank_payment` и push-уведомления, хотя платежи записывались в БД.
5. **Т-Банк опрос POS-терминалов**: В задаче `sync_tbank_terminals_task` (`tbank_tasks.py`) при поступлении новых оплат по терминалам эквайринга также не отправлялись WebSocket-сообщения и push-уведомления.

## Выполненные изменения:
1. **iiko_sync_service.py**:
   - Реализована безопасная рассылка WebSocket сообщений: методы `send_websocket_broadcast_safe` и `send_websocket_personal_safe` работают в любом событийном цикле и подходят для синхронного/асинхронного контекстов.
   - Добавлена отправка WebSocket трансляций с типами `order_cancelled` и `order_changed` при смене статуса заказа.
   - Добавлена отправка Web Push уведомлений администраторам о смене статуса.
   - Добавлена детекция снятия курьера с заказа, отправка WS события `delivery_unassigned` и Web Push курьеру об отмене доставки.
2. **courier.vue**:
   - WebSocket обработчик дополнен типами `delivery_unassigned`, `change_address`, `order_changed` для вызова реактивного обновления списков (`fetchData(true)`).
3. **tbank.py**:
   - Внедрена отправка WS-события `new_bank_payment` и Web Push для каждой новой транзакции, импортируемой из выписки по API.
4. **tbank_tasks.py**:
   - Добавлена отправка Web Push уведомления при получении платежей по POS-терминалам эквайринга в фоновой задаче опроса.
