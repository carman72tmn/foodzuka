# Журнал задачи: Интеграция с телефонией Mango Office (ВАТС) по API
Дата: 2026-09-05
Сессия: loggemini_2026_09_05_mango_office_integration

## Цель задачи
Добавить в панель администратора в меню «Система» раздел «Интеграция с Mango» (/settings/mango) с поддержкой всех возможностей API телефонии Mango Office (ВАТС):
- Настройки API подключения (vpbx_api_key, vpbx_api_salt, URL, Webhook).
- Генерация и проверка цифровой подписи SHA-256.
- Прием вебхуков (events/call, events/recording, events/summary) в реальном времени.
- Автоматическое определение клиентов по номеру телефона звонящего из базы `customers`.
- Журнал вызовов с фильтрами, статусами, длительностью и аудио-плеером записей.
- Функционал Click-to-Call (звонок из CRM в 1 клик).
- Завершение звонка (Hangup) и отправка SMS через Mango.
- Справочник линий и операторов ВАТС.
- Полные подробные инструкции по настройке и интеграции.

## Ход выполнения и результаты
1. Разработаны модели базы данных `MangoSettings` и `MangoCallLog` (таблицы `mango_settings` и `mango_call_logs`).
2. Созданы и применены индексы для быстрого поиска по номерам, статусам и клиентам.
3. Реализован сервис `MangoService`:
   - Расчет и валидация цифровой подписи SHA-256 (`sign = sha256(key + json + salt)`).
   - Обработка входящих событий (Appeared, Connected, Disconnected, Recording).
   - Авто-поиск звонящего в таблице `customers` с фиксацией `customer_id` и имени гостя.
   - Метод Click-to-Call (`commands/callback`), Hangup, SMS, Users.
   - Стриминг аудиофайлов для плеера без ограничений CORS.
4. Разработан роутер `app/api/mango.py` со всеми эндпоинтами и подключен в `main.py`.
5. Добавлены права RBAC `settings_mango_view` и `settings_mango_edit` в `seed_rbac.py` и назначены ролям администраторов в PostgreSQL.
6. Разработан интерфейс `mango.vue` (4 интерактивные вкладки) и стили `mango.css`.
7. Пункт добавлен в навигацию `NavItems.vue`, `routes.js`, `RoleList.vue`.
8. Проведена локальная сборка и сборка на VPS сервере.
9. Выполнено сквозное тестирование эмулятором вебхука и проверена фиксация звонка для тестового клиента +79220079019.
10. Обновлены файлы учета и документации: `system_faq.md`, `sql_faq.md`, `sitenav.md`.
