# Лог сессии: Исследование возможности интеграции TeraBox

- **Дата и время**: 11.06.2026 09:58 (UTC+5)
- **Задача**: Исследование возможности подключения облачного хранилища TeraBox по FTP/WebDAV/API для использования в качестве файлового архива сайта.
- **Статус**: Выполнено (информационный ответ).

## Результаты исследования:
1. **FTP / WebDAV**: TeraBox не предоставляет официальной поддержки протоколов FTP или WebDAV для обычных пользователей.
2. **API**: Официальный TeraBox Open Platform API закрыт и доступен только для авторизованных партнеров (enterprise-уровень).
3. **Обходные пути**:
   - Использование неофициальных скриптов/парсеров на основе токена авторизации (ndus cookie). Метод нестабилен и небезопасен.
   - Использование неофициальных сборок Rclone (например, `rclone-extra` или `bclone`) для монтирования на сервере. Подходит для фоновых бэкапов, но ненадежно для постоянной работы веб-приложения.
4. **Рекомендации**: Для полноценного файлового хранилища на сайте рекомендуется использовать S3-совместимые облака (Yandex Object Storage, VK Cloud) или диски с официальным WebDAV (Яндекс.Диск, Nextcloud).

Изменений в коде проекта не производилось.
