# Лог исследования проблемы отображения изображений товаров из iiko меню
Дата: 2026-06-02
Время: 14:20 (UTC+5)

## Выявленные проблемы:
1. В настройках iiko (`iiko_settings` в БД) флаг `use_v2_menu` равен `false` (`f`). Из-за этого синхронизация меню происходит по классической схеме Nomenclature API, где ссылки на картинки присутствуют только у 4 продуктов (сетов), а у остальных 99% продуктов ссылки отсутствуют.
2. Во внешнем меню (API v2 / Cloud Menu) с ID `79052`, которое выбрано в настройках, картинки есть у 290 из 294 товаров. Однако они вложены внутрь списка размеров: `itemSizes[0].buttonImageUrl`.
3. В коде бэкенда `backend/app/services/iiko_sync_service.py` в методе `_sync_from_external_menu_sync` ссылка на картинку извлекается с верхнего уровня: `item_data.get("buttonImageUrl")`. Поскольку на верхнем уровне ее нет, при потенциальном включении `use_v2_menu` картинки все равно не импортировались бы.
4. В админ-панели в шаблоне `admin/resources/js/components/OrderDetailModal.vue` отсутствует отображение картинок товаров в таблице состава заказа. Также в `order_items_details` (JSONB) картинки не сохраняются на бэкенде при синхронизации/создании заказа.

## План решения:
1. Изменить в бэкенде `_sync_from_external_menu_sync` извлечение `image_url` на `item_data.get("buttonImageUrl") or (sizes[0].get("buttonImageUrl") if sizes else None)`.
2. Включить `use_v2_menu = true` в базе данных.
3. Добавить обогащение поля `image_url` для каждого элемента заказа в `iiko_sync_service.py` при сохранении в `order_items_details`.
4. Внедрить вывод картинок блюд в таблицу состава заказа в `OrderDetailModal.vue` в админ-панели.
5. Выгрузить изменения на VPS, запустить полную синхронизацию меню для скачивания картинок, проверить работоспособность.
