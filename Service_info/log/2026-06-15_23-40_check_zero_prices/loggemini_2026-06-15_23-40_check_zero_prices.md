# Лог исследования: Сборный товар выгружается с ценой 0 руб

**Дата и время:** 2026-06-15 23:40 (время локальное)  
**Задача:** Выяснить, почему сборный товар (например, Сборный ВОК) выгружается с ценой 0 руб, хотя во внешнем меню iiko указана цена 115 руб.

## Ход исследования

1. **Анализ БД на VPS:**
   Запущен скрипт `check_zero_products.py`. Обнаружено, что в БД у товара **"Сборный ВОК"** (iiko_id: `8aff0de0-dc6a-4cea-99d2-733293122c0d`) цена в таблицах `products` и `product_sizes` установлена в `0.00` руб.
   
2. **Анализ локального дампа меню (`menu_dump.json`):**
   В локальном файле `menu_dump.json` (внешнее меню) у товара "Сборный ВОК" цена была указана как `115.0` руб.

3. **Запрос живого API iiko Cloud:**
   Запущен скрипт `check_live_menu.py`, который выполнил запрос `/api/2/menu/by_id` к живому API iiko Cloud для организации "Тюмень" (ID: `2704eeae-dc5f-4c9f-9b81-375c454dd5bd`) по меню "Меню для админки" (ID: `79052`).
   
   В ответе живого API для Сборного ВОК пришла цена `null`:
   ```json
   "prices": [
     {
       "organizationId": "2704eeae-dc5f-4c9f-9b81-375c454dd5bd",
       "price": null
     }
   ]
   ```
   Также цены `null` вернулись для всех его модификаторов (ингредиентов).

4. **Анализ ценовых категорий:**
   Запущен скрипт `check_nomenclature_categories.py`. Категорий цен в номенклатуре организации найдено 0.

## Вывод и рекомендации
В базе данных сайта цена сохраняется как `0.00` руб., потому что официальное API iiko Cloud на запрос меню возвращает для этого товара цену `null` (пустое значение). Бэкенд корректно обрабатывает это значение, заменяя его на `0`.

Для исправления ситуации пользователю необходимо:
1. Проверить цену товара "Сборный ВОК" в iiko Office (RESTO). Если она там 0, установить базовую цену 115 руб.
2. Проверить настройки ценообразования во внешнем меню "Меню для админки" в личном кабинете iiko Web.
