## Состояние до изменений

1. В методе `sync_tbank_statement` в файле `backend/app/api/tbank.py` ответ от API выписки Т-Банка (`GET /openapi/api/v1/statement`) присваивался переменной `real_ops = response.json()`.
   Однако API Т-Банка возвращает словарь со структурой `{ "operations": [ ... ] }`, а не плоский список. Из-за этого итерация `for op in ops_to_process:` происходила по ключам словаря (строкам), что приводило к пропуску/TypeError и выгрузке 0 транзакций.
2. Любые ошибки выполнения запроса (неверный токен, проблемы с TLS-сертификатом, ошибки HTTP 403/401) перехватывались блоком `except Exception` и гасились в логах бэкенда, возвращая статус `"success": True` и `"new_operations_added": 0`. Это не позволяло администратору увидеть реальную ошибку в UI.
