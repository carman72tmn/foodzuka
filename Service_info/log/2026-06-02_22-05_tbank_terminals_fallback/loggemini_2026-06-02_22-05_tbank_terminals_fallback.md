* **Задача**: Исправление SyntaxError в файле `tbank.py` и добавление мягкого фолбэка на `demo_terminals` и основной `settings.terminal_key` в случае сбоев API эквайринга Т-Банка.

## Состояние до изменений

В файле `backend/app/api/tbank.py` в блоке метода `get_tbank_terminals` (строки 194-354) присутствуют ошметки битого кода после предыдущего сбоя редактирования:
- Присутствует дублирующий код обработки ответа Т-Банка внутри блока `finally` (строки 309-350), включая некорректное выражение `pass if "terminals" in api_data:`.
- Это приводит к невозможности запустить бэкенд из-за SyntaxError.

## Планируемые изменения

1. Полностью заменить метод `get_tbank_terminals` в `backend/app/api/tbank.py` на чистую, синтаксически корректную реализацию с защищенными блоками `try/except`.
2. Реализовать ловлю абсолютно всех исключений (`Exception`) при вызове OpenAPI Т-Банка, логирование их как `warning` и возврат фолбэк-списка (основной `terminal_key` из настроек + демо-терминалы).
3. Проверить корректность синтаксиса локально через `py_compile`.
4. Задеплоить на VPS с перезапуском контейнеров.

## Бэкап исходного метода (для возможности отката)

Ошметки кода со строками 194-354 были заменены. Оригинальный файл `tbank.py` на сервере VPS `vezuroll` находился в стабильном рабочем состоянии, поэтому бэкап был получен напрямую с него перед внесением изменений.

1. **Редактирование `tbank.py`**:
   - Метод `get_tbank_terminals` переписан с нуля. Удалены синтаксически некорректные строки `finally` и ошметки старого кода (строки 309-354).
