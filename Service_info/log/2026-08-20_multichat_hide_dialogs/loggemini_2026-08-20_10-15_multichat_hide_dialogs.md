# Отчет по задаче: Скрытие (Архивация) чатов в Мультичате

**Дата**: 20.08.2026 10:15 (UTC+5)  
**Статус**: Выполнено успешно, протестировано на VPS `vezuroll`.

---

## 1. Постановка задачи
Добавить возможность скрывать чаты из списка диалогов Мультичата, чтобы они не отображались в общем списке, с возможностью их просмотра и возврата обратно.

---

## 2. Выполненные работы

### База данных (PostgreSQL `foodtech-db`):
1. Создана таблица `multichat_hidden_dialogs`:
   - `id`: SERIAL PRIMARY KEY
   - `channel`: VARCHAR NOT NULL (индексировано)
   - `peer_id`: VARCHAR NOT NULL (индексировано)
   - `created_at`: TIMESTAMP UTC (индексировано)
   - Уникальный составной индекс `ix_multichat_hidden_channel_peer` на `(channel, peer_id)`.

### Бэкенд (`backend/app/models/chat.py`, `backend/app/api/multichat.py`):
1. Создана модель SQLModel `MultichatHiddenDialog`.
2. Реализован эндпоинт `POST /api/v1/multichat/dialogs/{channel}/{peer_id}/hide` (`toggle_hide_dialog`):
   - Если запись уже есть — удаляет её и возвращает `{"status": "unhidden", "is_hidden": False, "message": "Диалог возвращен в общий список"}`.
   - Если записи нет — создает её и возвращает `{"status": "hidden", "is_hidden": True, "message": "Диалог скрыт из общего списка"}`.
3. В `GET /api/v1/multichat/dialogs` добавлена пакетная загрузка скрытых чатов и параметр `hidden_only`:
   - По умолчанию скрытые диалоги исключаются из общего списка.
   - При `hidden_only=true` возвращаются только скрытые диалоги.
   - В каждый объект диалога передается флаг `is_hidden: bool`.

### Фронтенд (`admin/resources/js/pages/multichat/index.vue`):
1. **Быстрые фильтры**:
   - В верхнюю панель фильтрации сайдбара добавлены 3 режима:
     - **Все** (`setFilterMode('all')`)
     - **Новые** (`setFilterMode('unread')`)
     - **Скрытые** (`setFilterMode('hidden')`)
2. **Кнопка скрытия в списке диалогов**:
   - В строку каждого чата добавлена кнопка действия `toggleHide(dialog)` с иконками `bx-hide` / `bx-show`.
3. **Кнопка скрытия в шапке активного чата**:
   - Добавлена кнопка «Скрыть чат» / «Вернуть в список».
   - Добавлена плашка «Скрытый чат» (`VChip`) рядом с контактами собеседника.
4. **Интерактивное обновление**:
   - При скрытии диалог немедленно удаляется из видимого основного списка с уведомлением через всплывающий `toast`.
