Дата: 11.06.2026
Время: 18:30 (местное время ассистента)

## Описание задачи
Обеспечить корректную замену шорткодов в шаблонах уведомлений при использовании двойных фигурных скобок с точечной нотацией:
- `{{customer.phone}}` — Телефон клиента
- `{{customer.bonus_points}}` — Баланс бонусов
- `{{customer.categories}}` — Категории (метки) клиента
- `{{customer.notes}}` — Заметки о клиенте
- `{{order.address}}` — Адрес заказа

## Локализованная проблема
1. Бэкенд в `mailing_cascade_service.py` ожидал переменные в одинарных скобках без префиксов (например, `{customer_phone}`, `{address}`).
2. При использовании двойных фигурных скобок они не заменялись или заменялись частично (оставались одиночные скобки, например `{+79220079019}`), если одинарные скобки обрабатывались в цикле раньше.
3. Поля заметок гостя (`customer.notes`) и категории (`customer.iiko_categories`) отсутствовали в словаре доступных переменных.

## Внесенные изменения
В файле **c:\Users\v_kva\.gemini\antigravity\scratch\foodtech\backend\app\services\mailing_cascade_service.py** обновлен метод `render_template`:
1. Добавлено извлечение бонусов гостя (из `bonus_points` или `vk_bonus_balance`).
2. Добавлено извлечение заметок гостя (`notes`).
3. Добавлено извлечение категорий гостя (`iiko_categories`, которые теперь объединяются в строку через запятую).
4. Расширен словарь `variables`, содержащий все возможные варианты синтаксиса переменных.
5. **Важно:** ключи с двойными фигурными скобками (`{{...}}`) помещены в словарь в самую первую очередь, а с одинарными (`{...}`) — во вторую. Это гарантирует, что двойные скобки заменяются целиком, предотвращая образование остаточных одиночных скобок.

4. Скрипт тестирования запущен внутри контейнера: `docker exec -i foodtech-backend python /app/test_template_render.py`.
5. Результаты тестов: все переменные (включая сложные с точечной нотацией и новые заметки/категории) были успешно заменены на реальные данные без фигурных скобок. Тест завершился с `SUCCESS`.
6. Скрипт деплоя удалил тестовый файл с VPS.
