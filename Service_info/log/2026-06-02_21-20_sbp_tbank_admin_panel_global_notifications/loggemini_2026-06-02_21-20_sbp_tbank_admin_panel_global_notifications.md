# Лог сессии: Глобальные всплывающие уведомления о новых платежах СБП/T-Pay в админ-панели (WebSockets)
**Дата/время**: 2026-06-02 21:20 (UTC+5)
**Задача**: Реализовать мгновенные всплывающие уведомления (Toasts) о новых банковских платежах по СБП и T-Pay в админ-панели на любой открытой странице, используя существующий канал WebSockets.

---

## 🔍 Исследованные возможности
1. **Канал WebSockets**: В бэкенде в `chat.py` реализован WebSocket эндпоинт `/ws` и менеджер подключений `ConnectionManager`. Фронтенд (`chatStore.js`) подключается к нему при авторизации для чата.
2. **Возможность интеграции**: Мы можем использовать этот канал для рассылки системных уведомлений. При получении нового платежа бэкенд может делать `broadcast` специального WebSocket сообщения, а фронтенд в глобальном макете `DefaultLayoutWithVerticalNav.vue` будет ловить его через Pinia-стор и выводить красивый Toast.

---

## 🛠️ Выполненные доработки

### 1. Бэкенд (`backend/app/api/tbank_webhooks.py`)
- Во все три эндпоинта входящих вебхуков Т-Банка (`/payment-status`, `/sbp-qr`, `/account-info`) при создании новой уникальной транзакции добавлена рассылка WebSocket сообщения:
  * Получает event loop и в фоновом режиме запускает `manager.broadcast()` с телом:
    `{"type": "new_bank_payment", "amount": float, "method": str, "customer": str, "order_id": int}`
  * Это позволяет передавать информацию о платеже всем активным сотрудникам в реальном времени.

### 2. Фронтенд: Стор чата (`admin/resources/js/stores/chatStore.js`)
- Добавлена новая реактивная переменная Pinia `paymentNotification` для хранения параметров всплывающего уведомления:
  `const paymentNotification = ref({ show: false, amount: 0, method: '', customer: '', orderId: null })`
- В обработчик WebSocket сообщений `ws.value.onmessage` добавлена фильтрация по типу `new_bank_payment`:
  * При получении сообщения этого типа, Pinia обновляет `paymentNotification`, переводя `show` в `true` и заполняя параметры транзакции.

### 3. Фронтенд: Глобальный шаблон (`admin/resources/js/layouts/components/DefaultLayoutWithVerticalNav.vue`)
- В самый низ `<template>` перед закрывающим тегом `</VerticalNavLayout>` интегрирован красивый Vuetify-компонент `<VSnackbar>`:
  * Он привязан к `chatStore.paymentNotification.show` и всплывает в правом верхнем углу при приходе платежа.
  * Отображает красивую зеленую плашку, иконку кошелька/карты, сумму поступления, способ оплаты (СБП, T-Pay, Эквайринг), имя плательщика и номер сопоставленного заказа.
  * Работает глобально: администратор увидит уведомление на **любой** странице админки, где бы он ни находился.
