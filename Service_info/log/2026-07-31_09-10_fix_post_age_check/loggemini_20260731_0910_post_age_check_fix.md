# Лог сессии: Исправление проверки срока давности постов
**Дата**: 2026-07-31
**Время**: 09:10 (местное)
**Задача**: Исправить ошибку, при которой не работала настройка срока давности постов (начислялись баллы за старые посты).

## Описание проблемы:
1. В VK Callback API приходят события `like_add`, `wall_reply_new` и `wall_repost`.
2. Бэкенд вызывает метод `get_post_info` из `vk_activity_service.py` для получения даты публикации поста.
3. `get_post_info` отправлял запрос к методу `wall.getById` через `call_vk_api`, используя токен группы (`vk_bot_token`).
4. VK API запрещает вызывать методы семейства `wall.` (такие как `wall.getById` и `wall.get`) с авторизацией группы, возвращая ошибку:
   `{'error_code': 27, 'error_msg': 'Group authorization failed: method is unavailable with group auth.'}`
5. Из-за этой ошибки `get_post_info` всегда возвращал `None`.
6. Функция проверки лимитов `is_post_eligible_by_age_and_keywords` при отсутствии информации о посте (`post_info is None`) возвращала `True` (считая пост подходящим), что приводило к полному пропуску проверок `post_max_age_days` и `period_start_date`. Пользователям начислялись баллы за любые старые посты.

## Решение:
1. Изменен метод `get_post_info` в `vk_activity_service.py`: теперь он пытается найти активное подключение `VkBotConnection` по `owner_id` (который равен `-group_id`) и использовать `vk_user_token` (токен пользователя), если он задан в настройках подключения.
2. Протестирована работа метода `wall.getById` с токеном пользователя на сервере VPS: запросы выполняются успешно, возвращается валидный список постов с датами публикации.
3. Код обновлен на сервере VPS, контейнер `foodtech-backend` перезапущен.
