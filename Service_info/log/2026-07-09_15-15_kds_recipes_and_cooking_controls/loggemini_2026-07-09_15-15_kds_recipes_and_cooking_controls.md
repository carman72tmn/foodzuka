# Лог изменений: Управление кухней в деталях заказа и техкарты заготовок

**Дата:** 09.07.2026  
**Задача:** KDS 2.0 (управление приготовлением из карточки заказа, техкарты заготовок)  
**Статус:** Выполнено, готово к деплою на VPS

---

## 1. Проблема и Решение

1. **Отсутствие управления кухней в карточке заказа (OrderDetailModal.vue)**  
   * **Проблема:** В админке при просмотре заказа (модалка `OrderDetailModal.vue`) выводится список товаров из сырого JSON `order_items_details`, который не связан с нашей кухонной таблицей `order_items`. Из-за этого оператор не видит статусы приготовления отдельных блюд и не может начать приготовление или отметить готовность блюда/всего заказа.  
   * **Решение:** 
     - В Pydantic-схему `OrderItemResponse` добавлены поля статуса кухни (`kitchen_status`, `kitchen_started_at`, `kitchen_ready_at`, `kitchen_zone_id`), чтобы API `/api/v1/orders/` отдавал актуальные кухонные статусы для каждого элемента в `order.items`.
     - В `OrderDetailModal.vue` добавлен метод сопоставления сырых позиций с объектами `OrderItem` (`getKitchenItem`).
     - В таблицу товаров добавлен столбец "Кухня", выводящий интерактивные кнопки («Начать готовить» / «Готово» / бейдж «Готово») для каждой позиции заказа.
     - В правую колонку модалки добавлена общая панель действий кухни, позволяющая переводить весь заказ по статусам KDS («Начать готовить», «На сборку», «Собран», «Готов полностью»).
     - В `index.vue` и `courier.vue` привязан обработчик события `@update:order`, который обновляет состояние без жесткой перезагрузки страницы (без F5).

2. **Проблема с техкартами сетов и вложенных заготовок**  
   * **Проблема:** В KDS-экране повара и в деталях заказа при попытке кликнуть на вложенную заготовку/ролл из состава сета, техкарта не открывалась и выдавала ошибку 404. Причина в том, что при синхронизации техкарт из iiko Resto (`sync_kitchen_recipes_and_zones`), если товара нет в меню доставки сайта (таблица `products`), его техкарта пропускалась.
   * **Решение:** 
     - Изменен метод синхронизации техкарт. Теперь, если товар из iiko отсутствует в локальной таблице `products`, он автоматически создается как служебный неактивный товар (`is_available = False`, `price = 0`).
     - Благодаря этому в БД создаются записи для всех заготовок, полуфабрикатов и промежуточных роллов, что позволяет загрузить их техкарты по API `GET /api/v1/kitchen/recipes/by-iiko-id/{iiko_id}`.
     - В `OrderDetailModal.vue` встроен диалог просмотра техкарты с KDS-экрана с поддержкой стека истории переходов («Назад») и кликабельности вложенных позиций.
