## 2. Выполненные изменения

### База данных (PostgreSQL)
Выполнена миграция таблицы `ai_site_assistants`, добавлены столбцы:
- `allow_external_queries` (BOOLEAN, default TRUE)
- `allow_iiko_api_queries` (BOOLEAN, default FALSE)
- `allow_iiko_export` (BOOLEAN, default FALSE)
- `allowed_external_tools` (JSONB, default `["weather", "general_search", "consulting"]`)
- `iiko_allowed_actions` (JSONB, default `["read_orders", "read_menu", "read_stop_list"]`)
- `enable_analytics_learning` (BOOLEAN, default TRUE)

### Бэкенд (FastAPI, SQLModel)
1. **`backend/app/models/ai_assistant.py`**:
   - Обновлена модель `AiSiteAssistant` с новыми полями ограничений и аналитики.
2. **`backend/app/api/ai_assistants.py`**:
   - Внедрена схема `AssistantUpdateSchema` с `ConfigDict(extra="ignore")` и опциональными полями, что предотвращает ошибку 422 при сохранении формы и частичных обновлениях.
   - Добавлен эндпоинт `PATCH /api/v1/ai-assistants/{id}/toggle` для быстрого и надежного переключения статуса.
   - Добавлен эндпоинт `GET /api/v1/ai-assistants/all-active` для наполнения селектора персонажей во фронтенде.
   - Добавлен эндпоинт `GET /api/v1/ai-assistants/analytics/observations` с детерминированным расчетом метрик на живых заказах таблицы `orders`.
   - Добавлен эндпоинт `POST /api/v1/ai-assistants/analytics/generate-ai-summary` (ультра-компактный запрос на ~150 токенов).
3. **`backend/app/services/ai_assistant_service.py`**:
   - Исправлена санитизация типов (преобразование строк в целые числа, обработка `None` для внешних ключей).
   - Внедрен метод `get_analytics_observations()`.
   - В системный промпт помощника добавлены правила соблюдения ограничений на внешние запросы и права доступа к iiko API.
