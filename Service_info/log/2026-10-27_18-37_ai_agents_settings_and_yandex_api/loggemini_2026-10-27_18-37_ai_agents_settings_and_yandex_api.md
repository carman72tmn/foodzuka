# Лог задачи: Настройка ИИ агентов и исправление API Яндекс
Дата: 2026-10-27 18:37

## Описание задачи
1. Ошибка при добавлении API от Яндекса в админке.
2. В настройках API ключа требуются поля: Секретный ключ, Идентификатор API-ключа.
3. В настройках ИИ агентов (Система -> ИИ агенты) в ролях сайта и песочнице добавить возможность создавать агентов и писать промпты для агентов с помощью подключенных ИИ агентов без ограничений, с возможностью получения доступных данных для работы и обработки.


## Выполненные работы

1. **Диагностика и устранение ошибки API Yandex Cloud (400 Bad Request / model_uri error)**:
   - Причина ошибки: в Yandex Cloud URI модели формируется строго в формате `gpt://<folder_id>/<модель>`. При отсутствии Folder ID (`client_id`) запрос падал с ошибкой `invalid model_uri`.
   - В форме подключения YandexGPT выделены 3 явных поля:
     - `Folder ID каталога` (префикс `b1g...`) — обязателен для формирования model_uri.
     - `Секретный ключ` (префикс `AQVN...`) — секрет сервисного аккаунта.
     - `Идентификатор API-ключа` (префикс `aje...`) — Key ID сервисного аккаунта.
   - Реализована функция умной вставки (`@paste`) в форме настроек Yandex: при копировании ключей система автоматически распознает префиксы `b1...`, `AQVN...`, `aje...` и раскладывает их по соответствующим полям.
   - В бэкенде добавлена автокоррекция случайной перестановки местами `api_key` и `key_id`, а также валидация с информативными подсказками на русском языке.

2. **Реестр доступных данных сайта (`AVAILABLE_DATA_SOURCES`)**:
   - Реализован эндпоинт `GET /api/v1/ai-agents/data-catalog`, возвращающий доступные домены данных сайта:
     1. `olap_stats`: Финансовая и OLAP-аналитика (iiko Resto) — выручка по дням, средний чек, количество гостей и чеков, суммы скидок, оплаты налом и картами.
     2. `orders`: Поток заказов сайта в реальном времени — номера, статусы, суммы, примененные скидки и состав позиций.
     3. `customers`: База клиентов и программа лояльности iikoCard — баланс баллов, частота визитов, новые гости, категории лояльности.
     4. `nps_reviews`: Отзывы гостей и оценки качества NPS (1-5 звезд) с комментариями.
     5. `menu_catalog`: Каталог меню, категории, актуальные цены и стоп-листы.
     6. `promo_codes`: Действующие промокоды, скидки в %, подарочные позиции и активность.
   - Метод `gather_site_context` динамически собирает только те данные, к которым у агента открыт доступ в `permissions_config.data_sources`.

3. **Генератор системных промптов через подключенные ИИ (`POST /api/v1/ai-agents/generate-prompt`)**:
   - Возможность генерировать глубокие структурированные промпты без искусственных ограничений длины (до 4000 токенов) через любой активный ИИ.
   - В промпт-генератор заложен специализированный мета-промпт Prompt Engineering, знающий предметную область доставки суши и роллов VezuRoll, структуру базы данных и метрики iiko.
   - Генератор возвращает название роли, код агента, системную инструкцию и рекомендуемые источники данных с кнопкой «Применить к агенту».

4. **Создание и управление агентами (Кастомные роли)**:
   - Добавлены эндпоинты `POST /api/v1/ai-agents/site-agents` (создание агента) и `DELETE /api/v1/ai-agents/site-agents/{agent_code}` (удаление кастомного агента).
   - В интерфейсе админки:
     - Кнопка «+ Создать агента».
     - Модальное окно с выбором провайдера, модели, чекбоксами доступных данных и кнопкой генерации промпта.
     - Бейджи «Системный» / «Кастомный» и цветные чипсы доступных данных для каждой карточки.
     - Возможность удаления только кастомных агентов (системные защищены).

5. **Песочница тестирования агентов (`POST /api/v1/ai-agents/execute`)**:
   - Интерактивный запуск запросов к любому агенту прямо из интерфейса.
   - Переключатель «Передавать реальные данные из БД» (Live Data).
   - Вывод аналитического ответа агента с метаданными (использованная модель, затраченные токены, факт передачи живых данных).
