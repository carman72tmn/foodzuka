# Сессия: Редактор прав для ролей пользователей
Дата и время: 16.06.2026 15:03 (UTC+5)

## Описание задачи
Настройка ролей и доступов к разделам админки.
Необходимо:
1. Задать детальные права для каждого раздела, подраздела, вкладки и категории админ-панели.
2. Реализовать 2 уровня доступа для каждой сущности:
   - Просмотр
   - Редактирование
3. Скрывать элементы из интерфейса (меню, табы, кнопки редактирования), если к ним нет доступа.
4. Защитить прямые переходы по ссылкам в роутере Vue.
5. Обеспечить максимальную безопасность на бэкенде.
