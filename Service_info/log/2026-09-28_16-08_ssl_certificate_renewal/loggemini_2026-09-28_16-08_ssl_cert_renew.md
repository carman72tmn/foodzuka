# Сессия: 2026-09-28 16:08
Задача: Расследование ошибки net::ERR_CERT_DATE_INVALID при входе в админку vezuroll.ru и продление SSL-сертификата.

## Проблема
Пользователь столкнулся с ошибкой `net::ERR_CERT_DATE_INVALID` при открытии `vezuroll.ru/admin`.
Браузер сообщал: "Срок действия сертификата vezuroll.ru истек в последний день".

## Причина
1. Сертификат Let's Encrypt для vezuroll.ru действовал с 30 июня 2026 по 28 сентября 2026 08:08:05 GMT.
2. В 08:08 GMT (13:08 по местному времени) 90-дневный срок действия сертификата истек.
3. Фоновый контейнер `foodtech-certbot`, отвечающий за фоновое автообновление каждые 12 часов, не был запущен в docker ps (был остановлен ранее при перезапусках сервисов).

## Действия
1. Конфликтный файл `~/foodzuka/certbot/conf/renewal/72roll.ru.conf` перенесен в бэкап.
2. Сертификат vezuroll.ru успешно перевыпущен (`cert3.pem`, валиден до 27 декабря 2026 года).
3. Перезапущен Nginx: `docker compose restart nginx`.
4. Запущен постоянный фоновый контейнер certbot: `docker compose up -d certbot`.
5. Проверено соединение: `openssl s_client` и `curl -sIv https://vezuroll.ru/admin` подтвердили валидность сертификата и отсутствие предупреждений.

## Дополнение: Устранение задержки загрузки (белого экрана)
После обновления SSL при открытии админки наблюдался белый экран (задержка инициализации интерфейса).
Причина:
- Контейнер `foodtech-backend` (uvicorn) работал 11 дней без перезапуска, накопил нагрузку 95% CPU, сетевой обмен превысил 5 TB.
- Запросы проверки авторизации `/api/v1/auth/me` отвечали по 8-10 секунд (в Nginx фиксировался статус 499 - Client Closed Request).
- Vue Router / Pinia ожидали ответ auth эндпоинта, задерживая рендеринг формы входа.

Решение:
- Выполнен перезапуск сервисов: `docker compose restart backend worker`.
- Нагрузка CPU снизилась с 95% до 4.5%.
- Время ответа эндпоинтов авторизации сократилось с 8.4 с до 0.024 с (24 мс).
- Админ-панель успешно и быстро загружается.
