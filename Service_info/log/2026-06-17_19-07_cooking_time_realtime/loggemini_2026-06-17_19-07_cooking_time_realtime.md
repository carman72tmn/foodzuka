# Лог изменений Gemini: Реализация real-time обновления времени готовности заказа и уведомлений курьеров
Дата/Время: 2026-06-17 19:07 (MSK+2)
Сессия: 2026-06-17_19-07_cooking_time_realtime

## Описание задачи
1. По умолчанию показывать 0 минут в заказах.
2. Для заказов на доставку ставить время готовности.
3. Для курьеров, если время готовности не изменено в заказах, отображать "Время готовности не выставлено, ожидайте".
4. Отображать время готовности только когда его выставят в заказах.
5. Уведомлять курьера о том, что время готовности заказа установлено или изменилось.
6. Обновлять время готовности в панели курьера без перезагрузки (по WebSocket).

## Внесенные изменения

### 1. Бэкенд
* **app/models/order.py**: Изменено дефолтное значение `cooking_time_minutes` с `20` на `0`.
* **app/schemas/__init__.py**: В схеме `OrderResponse` дефолтное значение `cooking_time_minutes` изменено с `20` на `0`.
* **app/api/courier.py**: В список возвращаемых полей для курьера добавлено поле `"cooking_time_minutes"`.
* **app/api/orders.py**: В эндпоинте POST `/orders/{order_id}/cooking-time` реализована WebSocket-трансляция события `change_cooking_time` на все открытые панели, а также персональные уведомления для курьера:
  * Внутренний WebSocket-сигнал лично курьеру (для real-time).
  * Web Push уведомление.
  * Уведомление через VK / Telegram / MAX Messenger / SMS на основе настроек учетной записи курьера в `vk_bot_accounts`.

### 2. Фронтенд
* **OrderDetailModal.vue**:
  * Предустановлено стартовое значение `0` вместо `20`.
  * В список выбора `cookingTimeItems` добавлен `0` первым элементом (отображается как `0 мин.`).
  * Изменено текстовое отображение: при отсутствии значения выводится `0 мин.`.
* **orders/index.vue**:
  * В список `cookingTimeItems` добавлен `0` первым элементом.
  * Текстовое дефолтное значение изменено с `20` на `0`.
* **courier.vue**:
  * Заменено отображение времени на карточке заказа: если `cooking_time_minutes > 0` -> `Кухня: X мин.`, иначе оранжевая плашка `Время готовности не выставлено, ожидайте`.
  * Реализовано WebSocket подключение при монтировании, автоматическое реактивное обновление времени на лету при получении события `change_cooking_time` (сопровождается информационным Toast-сообщением) и перезагрузка списка при назначении курьера.

### 3. База данных и миграции
* Создан и выполнен скрипт `backend/app/scripts/update_cooking_time_default.py`, который сбросил старое дефолтное значение `20` в `0` для всех существующих заказов в БД.
