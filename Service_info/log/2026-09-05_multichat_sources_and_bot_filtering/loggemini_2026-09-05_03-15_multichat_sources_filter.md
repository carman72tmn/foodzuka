# Лог выполнения задачи: Разделение и детальная фильтрация по источникам, личным аккаунтам и ботам в Мультичате (05.09.2026)

## 1. Исходная проблема
- В Мультичате при выборе общего списка диалогов возникала путаница: верхние кнопки статуса («Все», «Новые», «Скрытые») и вкладки каналов с немыми иконками сливались.
- Не было явного разделения между личными аккаунтами (MAX Личный, VK Личный) и чат-ботами сообществ.
- В сообществах ВК невозможно было фильтровать отдельно конкретную группу (например, основную клиентскую группу «Довезука» ID: 186688777 и служебную курьерскую группу «Курьеры» ID: 234266390).

## 2. Реализованные изменения

### Backend (ackend/app/api/multichat.py):
1. В ручку GET /api/v1/multichat/dialogs добавлен параметр channel_id: Optional[str] = None.
2. В SQL-запрос Loose Index Scan (Skip Scan) добавлена поддержка фильтрации по channel_id (:channel_id = 'all' OR channel_id = :channel_id).
3. В возвращаемом объекте каждого диалога добавлено поле channel_id для точной идентификации группы или аккаунта.
4. Ключ кэша Redis расширен параметром channel_id.

### Frontend (dmin/resources/js/pages/multichat/index.vue):
1. **Динамическая загрузка источников**:
   - Автоматическая загрузка подключений групп ВК (etchVkBots -> GET /api/v1/vk/bots) и личных аккаунтов (etchAccounts -> GET /api/v1/multichat/accounts).
   - Формирование реактивного списка vailableSources со всеми активными аккаунтами и ботами.
2. **Разделение зон управления**:
   - **Верхняя строка**: строго статусы диалогов ([💬 Все], [✉️ Новые (N)], [👁️ Скрытые], кнопка «Прочитать все» и библиотека звуков).
   - **Панель категорий источников**:
     - [ 🌐 Все (Total) ]
     - [ 📱 Личные (N) ]
     - [ 🤖 Боты / Группы (N) ]
   - **Горизонтальная лента чипсов конкретных источников**:
     - Чипсы с фирменными иконками, цветами и точными названиями (MAX Личный, VK Личный, VK: Довезука, VK: Курьеры, MAX Бот, TG Бот, WhatsApp).
     - Индивидуальные красные бейджи с числом непрочитанных сообщений в каждом конкретном источнике.
3. **Расширенная панель фильтров (showFilters)**:
   - Селект выбора источника VSelect со всеми аккаунтами и ботами.
   - Синхронизация кнопки «Сбросить фильтры».
