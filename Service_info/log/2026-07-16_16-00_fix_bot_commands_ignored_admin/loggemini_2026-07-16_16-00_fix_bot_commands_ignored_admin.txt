Лог сессии: 2026-07-16_16-00_fix_bot_commands_ignored_admin
Задача: Исправление работы бота по ключевым командам ("Мой бонусный баланс" и др.) для администраторов/менеджеров.

Анализ проблемы:
Администратор сообщества (ID 6875740) тестирует отправку триггерной команды "Мой бонусный баланс".
Однако его ID занесен в список игнорируемых ID (`vk_parser_ignored_ids`) в настройках ВК.
В методе `handle_message` сервиса `backend/app/services/vk_service.py` на строке 265 стоит проверка:
```python
if vk_id and is_ignored_vk_id(vk_id, ignored_ids_str):
    logger.info(f"VK ID {vk_id} is in ignored list, skipping parser processing and history storage.")
    return
```
Из-за этого выполнение прерывается на самом раннем этапе. В результате:
1. Сообщения от администраторов не сохраняются в лог-историю сообщений.
2. Сообщения от них не обрабатываются командами ботов (`handle_bot_commands_and_fsm` не вызывается).
При этом назначение списка игнорируемых ID — не парсить от них фейковые заказы, а не блокировать работу команд ботов.

Решение:
Убрать раннюю проверку и `return` из начала `handle_message`.
Перенести проверку `is_ignored_vk_id` ниже, непосредственно перед извлечением номера заказа и проверкой истории сообщений на наличие номера заказа.
Это позволит командам ботов и записи переписки в историю работать для администраторов, но исключит их сообщения из логики парсинга заказов.

План проверки:
1. Применить изменения в локальном `backend/app/services/vk_service.py`.
2. Выгрузить изменения на VPS-сервер.
3. Провести сверку содержимого файла на VPS.
4. Перезапустить контейнеры backend и worker.
5. Проверить работу бота.
