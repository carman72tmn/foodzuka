**Задача**: Объединение колонок ID и IIKO в таблице заказов, увеличение кнопки выбора времени готовки, добавление назначения и переназначения курьера строго с открытой сменой доставки в iiko, удаление курьера из колонки типа заказа.

## 1. Задачи пользователя
1. В таблице заказов (/admin/orders) объединить столбцы «ID» и «IIKO» в один столбец с построчным выводом номеров и пояснениями (ID: #... и iiko: ...).
2. В столбце с выбором времени приготовления («Кухня / Курьер»):
   - Для заказов на доставку сделать поле/кнопку выбора времени покрупнее по высоте и ширине (28px x 84px).
   - Ниже второй строкой добавить возможность выбора курьера:
     - Если курьер еще не назначен: действие «+ Назначить курьера».
     - При нажатии открывать список для выбора СТРОГО курьеров с открытой сменой доставки в iiko Cloud.
     - Если курьер выбран: отображать «Курьер: <Имя курьера>» с пунктирным подчеркиванием.
     - При нажатии на назначенного курьера открывать меню для быстрого переназначения на другого курьера с открытой сменой в iiko.
3. Из столбца «ТИП ЗАКАЗА» (order_type_and_delivery) удалить отображение курьера во избежание дублирования.
4. В эндпоинте активных курьеров возвращать строго курьеров с открытой сменой доставки в iiko Transport API (/api/1/employees/couriers/active_location), отфильтровать системные аккаунты iiko (iikotransport, централизованная доставка и др.) и убрать фоллбэк на всех курьеров из базы данных.
