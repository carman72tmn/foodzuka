# Лог изменений: Фильтрация выписок Т-Банка строго по терминалам и СБП

**Дата:** 2026-06-02  
**Задача:** Настройка фильтрации входящих операций выписки, чтобы сохранять только реальные оплаты клиентов (терминалы эквайринга, СБП, QR, T-Pay) и отсечь все расходы, комиссии и прочие нецелевые операции.

## Выполненные изменения

### 1. Бэкенд (`backend/app/api/tbank.py`)
- В метод `sync_tbank_statement` добавлен фильтр типа операции: импортируются строго транзакции с типом `Credit`. Это полностью убирает все расходы по корпоративным картам (покупки в супермаркетах), комиссии и списания (которые приходят в выписке с положительной суммой, но имеют тип `Debit`).
- Добавлен текстовый контентный фильтр назначения платежа: проверяется наличие ключевых слов `терминал`, `эквайринг`, `сбп`, `tpay`, `t-pay`, `qr`, `зачисление средств` и отсутствие слов-исключений (`комисси`, `плата за пополнение`, `плата за обслуживание`, `процент на остаток`). Это оставляет в системе только целевые зачисления оплат клиентов.

### 2. База данных (VPS `vezuroll.ru`)
- Произведена полная очистка таблицы `tbank_statements` с помощью команды `TRUNCATE TABLE tbank_statements;` для удаления старого мусора (расходов по картам, комиссий).
- Произведен перезапуск контейнеров `backend` и `worker`.
