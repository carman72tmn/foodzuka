Задача: Исправление ошибки "API Error 401: Not authenticated at /api/v1/orders/"
Дата: 01.05.2026
Время: 20:59

Описание проблемы:
В логах backend-приложения появлялись частые (каждую минуту/30 сек) предупреждения `WARNING main API Error 401: Not authenticated at /api/v1/orders/`.
Это происходило из-за того, что открытые вкладки админ-панели (страница заказов) продолжают выполнять автообновление (polling) списка заказов каждые 30 секунд. Если сессия авторизации пользователя истекла (token expired), API возвращает ошибку 401, которая перехватывалась общим обработчиком и записывалась в логи как `WARNING`, создавая лишний мусор и спам.

Выполненные изменения:

1. `backend/main.py`:
- Изменен глобальный перехватчик `http_exception_db_handler`.
- Добавлено исключение для кодов 401 (Not authenticated) и 404 (Not found) в логике `logger.warning()`. Теперь эти ошибки API не записываются в лог с уровнем WARNING, чтобы не засорять логи при истечении сессии пользователей.

2. `admin/resources/js/pages/orders/index.vue`:
- В функции `loadOrders()`, которая вызывается по таймеру каждые 30 секунд, добавлена проверка статуса ответа `res.status === 401`.
- Если сервер возвращает 401, интервал автоматического обновления сбрасывается (`clearInterval(updateInterval)`), останавливая дальнейшие неавторизованные запросы к серверу со стороны клиентского браузера.

Дальнейшие действия:
Изменения внесены на локальной среде. Для применения на сервере VPS необходимо:
1. Выгрузить измененный `backend/main.py`.
2. Выгрузить измененный `admin/resources/js/pages/orders/index.vue`.
3. Сделать пересборку frontend (vue) на VPS.
4. Перезапустить контейнеры бэкенда.
