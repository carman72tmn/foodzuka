# ИСПРАВЛЕНИЕ ПЕРЕКЛЮЧЕНИЯ ВКЛАДОК В МОДАЛЬНЫХ ОКНАХ НОВЫХ БОТОВ
Дата: 24.10.2026 21:07 (UTC+5)

1. Причина:
В компоненте VkMarketingBotModal.vue при переключении вкладок через Vuetify VTabs значение v-model= activeTab приводилось к строковому типу (1, 2, 3). В блоках содержимого вкладок проверка производилась через строгое равенство (v-show=activeTab === 1, activeTab === 2 и т.д.). В JavaScript strict comparison 1 === 1 возвращает false, из-за чего все последующие вкладки оставались скрытыми.

2. Решение:
- На тег <VTab> добавлен явный обработчик клика: @click=activeTab = idx.
- Во всех блоках вкладок для всех 6 ботов условие проверки изменено на нестрогое сравнение (activeTab == 0, activeTab == 1, activeTab == 2, activeTab == 3).
- Фронтенд успешно пересобран (npm run build на VPS).
- Контейнеры foodtech-admin и foodtech-nginx перезапущены.
- Теперь все вкладки во всех 6 ботах переключаются плавно и без задержек.
