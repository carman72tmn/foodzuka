# Навигация по админ-панели (sitenav.md)

Полное дерево пунктов меню с описанием функционала.

### Основное меню

1.  **Рабочий стол (Dashboard)**
    - Общая статистика по заказам, выручке и курьерам.

2.  **Заказы (Orders)**
    - **Все заказы**: Список всех заказов из iiko.
      - **Индикаторы**: [NEW] Звезда (Новый клиент) и Щит (Статус риска) в столбце Клиент.
      - **К ОПЛАТЕ**: [NEW] Отображение остатка долга (`ост. X ₽`) для частично оплаченных заказов.
      - **ОПЛАЧЕНО**: [NEW] Отдельная колонка для отображения фактически внесенных на кассе средств (терминал/наличные).
      - **Ожидаем**: [NEW] Отображение даты для предзаказов на будущие периоды.
    - **Детали заказа**: Просмотр состава заказа, адреса, статуса. Блокировка изменений для закрытых заказов.
      - **[NEW] Примененные акции**: Детальный блок в правой колонке с информацией о программах лояльности iiko, маркетинговых кампаниях и использованных купонах/сертификатах.

3.  **Клиенты (Customers)**
    - **Все клиенты**: Список всех гостей.
      - **[NEW] Панель обслуживания**: Кнопки "Проверить ID", "Слияние по UID", "Слияние по телефону".
      - **[NEW] Фильтры дубликатов**: Кнопки для поиска клиентов с одинаковыми телефонами или UID.
    - **Карточка клиента (Премиальная 8-вкладочная)**:
      - **1. Анкета**: Основные данные (ФИО, пол, ДР, регистрация), маркетинговые статусы и категории iiko.
      - **2. Бонусы**: Текущий баланс (iiko Card), кнопки начисления/списания баллов, полная история транзакций.
      - **3. Заказы**: Глубокая история за 12 месяцев из iiko Cloud. Возможность просмотра деталей заказа iiko или локальной карточки заказа.
      - **4. Аналитика**: [NEW] Выгрузка статистики из iiko Server (OLAP): LTV, средний чек, частота и др. **[UPDATE 30.04]**: Данные кэшируются в БД. Добавлены индикаторы загрузки (`VProgressCircular`) для полей во время синхронизации.
      - **5. Риски**: Управление статусом "Высокий риск", указание причины. Визуальные индикаторы в шапке (Green/Yellow/Red).
      - **6. Адреса**: История адресов доставки с возможностью переключения статуса активности (Актуальный/Неактуальный).
      - **7. Уведомления**: Настройка маркетинговых подписок (Promo, Loyalty, Order Status) и логи отправленных сообщений.
      - **8. Дополнительно**: Техническая информация, RAW JSON данные из iiko для отладки.
    - **Синхронизация**: Кнопка массовой синхронизации и кнопка обновления в карточке.

4.  **Рассылки (Mailings)**
    - **Общие рассылки**: Маркетинговые рассылки по базе клиентов.
    - **Настройки Telegram Бота**: Ключи и параметры бота.
    - **Настройки VK Бота**: Ключи и параметры группы.
    - **Вкладка:** [Уведомления VK Бота](https://vezuroll.ru/admin/settings/vk-notifications) — Шаблоны уведомлений для гостей.
    - **Вкладка:** [Парсер ВК](https://vezuroll.ru/admin/settings/vk-parser) — Настройка автоматической связки заказов и VK ID.
    - **Вкладка:** [Настройка MAX](https://vezuroll.ru/admin/settings/max) — Интеграция с мессенджером MAX (рассылки по телефону, управление ботами).
    - **Вкладка:** [Настройка каскада](https://vezuroll.ru/admin/mailings/cascades) — [NEW 13.05.2026] Управление очередностью и условиями отправки уведомлений по разным каналам (VK, MAX Messenger, TG).
        - **Таб: Настройки и статистика**: Управление фразой-парсером, запуск сканирования истории и просмотр последних связок.
        - **Таб: Настройка уведомлений**: Настройка автоматических сообщений гостям при изменении статуса заказа.
        - **Таб: Мониторинг сообщений**: Полная статистика всех сообщений группы.

5.  **Система (System)**
    - **Сервер**: [NEW] Мониторинг системных ресурсов в реальном времени (CPU, RAM, Диск).
    - **Метки**: Управление тегами клиентов.
    - **Настройки iiko**: Ключи API и ID организации.
    - **Фоновые процессы**: [NEW] Мониторинг задач Celery, пауза, отмена.
    - **Логи синхронизации**: Логи пачек синхронизации гостей.
    - **Логи системы**: Технические логи ошибок.
    - **Обслуживание базы (Maintenance)**: [NEW] Инструменты для поиска клиентов без ID и объединения дублей. **[NEW 13.05]**: Добавлена регламентная задача ежедневной очистки логов ВК.

6.  **Отчеты (Reports)**
    - **Отчеты курьеров**: Детализация по доставкам. [NEW 05.05] При просмотре текущего дня автоматически запускается фоновая Celery-задача для синхронизации данных из iiko Resto OLAP.
    - **Выручка (OLAP)**: Финансовые отчеты.

7.  **Администрирование**
    - **Сотрудники**: Данные из iiko.
    - **Пользователи**: Доступ в админ-панель.

### Логика работы

- **Рекурсивная синхронизация**: Обрабатывает гостей пачками по 10 человек. Пауза 30 секунд. При возникновении ошибки процесс полностью останавливается до ручного вмешательства.
- **Ленивая синхронизация (On-Demand)**: Данные актуализируются из iiko при:
  - Открытии карточки клиента в админ-панели.
  - Поступлении нового заказа от клиента.
  - Изменении бонусного баланса (транзакции).
  - [NEW] Ручном запуске синхронизации.
  - [NEW 05.05] Запросе отчета курьеров (если в период входит "сегодня").
- **Управление задачами**: На странице "Фоновые процессы" можно контролировать выполнение массовых операций.

### Глобальный UX [NEW 30.04.2026]

- **Pull-to-Refresh**: На всех страницах админ-панели реализована поддержка свайпа вниз для обновления страницы на мобильных устройствах. Присутствует визуальный индикатор (спиннер).
